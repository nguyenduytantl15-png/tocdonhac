# Tốc Độ Nhạc

App Android phát nhạc có chỉnh tốc độ, cao độ, hẹn giờ tắt (giống Music Speed Changer).

## Tính năng
- Tốc độ 0.25x – 4.00x (bước 0.05), nút nhanh 0.5x / 0.75x / 1x / 1.25x / 1.5x / 2x
- Đổi cao độ ±12 nửa cung, giữ nguyên cao độ khi đổi tốc độ (hoặc chế độ “băng cassette”)
- Hẹn giờ tắt: 5–90 phút, tự nhập số phút, hoặc tắt khi hết bài; nhỏ dần âm lượng 20 giây cuối
- Lặp đoạn A-B (luyện nghe, tập hát, tập nhạc cụ)
- Danh sách phát, lặp tất cả / 1 bài, trộn bài, tua ±10 giây
- Phát nền, điều khiển từ thanh thông báo & màn hình khóa, tự dừng khi rút tai nghe
- Nhớ danh sách, bài đang nghe, vị trí, tốc độ khi mở lại
- “Mở bằng Tốc Độ Nhạc” từ trình quản lý file
